WhatsApp AI Responder Options

AI providers

Add one or more provider keys. Each profile can choose its own provider and model.

Model lists use the configured provider keys. Fallback model IDs are available if refresh fails.

For local testing this stores keys in Chrome local extension storage. For real use, put keys behind your own backend proxy.

User identity

Names that WhatsApp may use for your own messages. This helps the prompt avoid replying as the wrong person.

Profiles

Add one or more chat title snippets. Specific matching profiles appear before generic profiles in the WhatsApp menu.

Optional: add one or more contact names or phone-number snippets for direct chats. These are checked in addition to chat titles.

Debug history

Use this to inspect the exact system prompt, user prompt, selected message, model, and provider response. It is stored only in Chrome local extension storage.
